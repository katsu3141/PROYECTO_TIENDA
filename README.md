# 🛍️ PROYECTO TIENDA

Este es el repositorio del proyecto final de tienda desarrollado por katsu3141.

## 🎯 Descripción del Proyecto
Aplicacion hibrida para gestionar inventarios, realizar pedidos con vista cliente / administrador

## 🛠️ Tecnologías Utilizadas
* Angular / Ionic / Ts

## 🚀 Instalación (Pasos para correrlo localmente)
1. Clonar el repositorio: `git clone https://github.com/katsu3141/PROYECTO_TIENDA.git`
2. Navegar a la carpeta del proyecto: `cd PROYECTO_TIENDA` / cd taully-market-main
3. Instalar dependencias: `npm install`
